# Community Guidelines

Help us maintain a welcoming and productive community.

## Core Values

### Respect
- Treat all members with dignity
- Welcome newcomers
- Avoid personal attacks

### Quality
- Post thoughtful, well-structured content
- Provide context when asking questions
- Include code samples when relevant

### Collaboration
- Share knowledge freely
- Give credit where due
- Build on others' ideas constructively

## Posting Guidelines

### When Asking Questions

**Do:**
- Search for existing answers first
- Provide clear, specific details
- Include relevant code snippets
- Mention what you've already tried

**Don't:**
- Post vague questions
- Expect immediate responses
- Cross-post the same question

### When Answering

**Do:**
- Explain your reasoning
- Provide working examples
- Link to relevant resources
- Be patient with beginners

**Don't:**
- Post one-word answers
- Be condescending
- Copy-paste without attribution

## Content Standards

### Allowed
- Technical discussions
- Code reviews
- Learning resources
- Project showcases
- Career advice

### Not Allowed
- Spam or self-promotion
- Offensive content
- Confidential information
- Off-topic discussions

## Moderation

Posts that violate guidelines may be:
1. Edited for clarity
2. Moved to appropriate category
3. Removed if necessary

Repeated violations may result in restricted access.

## Recognition

Active, helpful members earn:
- Community badges
- Featured contributor status
- Invitation to beta programs
